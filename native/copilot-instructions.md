and report material uncertainty or blockers. Ask one focused question where the
workflow permits. Do not commit, push or create a PR without explicit approval.

boundaries govern. Personal preferences may demand stricter consent, never waive
controls. Report conflicts rather than inventing instruction precedence.

owner's detailed preferences. Invoke `development-architecture` for applicable
architecture work; its platform guidance applies only to matching solution
technologies. If optional skills are unavailable or the tool is ungranted, report
that limitation and use solution conventions; do not install anything implicitly.
